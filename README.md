# Ала-Тоо Inn: сайт гостиницы

Сайт на HTML, CSS и JavaScript с сервером на Node.js (Express). Работает на телефоне и компьютере.
Запуск: `npm start`. Сервер слушает адрес `0.0.0.0` и порт из `process.env.PORT` (если переменной нет, то 3000).

## Что внутри

```
ala-too-inn/
├── server.js            сервер Express: раздаёт сайт, принимает заявки
├── package.json         зависимости и команда npm start
├── render.yaml          необязательный файл настроек для Render
├── .gitignore           что не отправлять в GitHub
└── public/
    ├── index.html       страница
    ├── css/style.css    оформление
    └── js/
        ├── pricing.js   номера, туры, цены и расчёт (общий для сайта и сервера)
        └── app.js       поведение страницы: параллакс, форма, новости, рейтинги
```

Стоимость брони сервер пересчитывает сам по правилам из `pricing.js`, поэтому подменить цену в браузере нельзя.

## Часть 1. Запуск на вашем компьютере (Windows)

### 1. Установите Node.js
1. Откройте https://nodejs.org и скачайте версию **LTS**.
2. Запустите установщик, во всех окнах нажимайте «Next», галочки не меняйте.
3. Закройте и снова откройте PowerShell (меню «Пуск», слово `PowerShell`).
4. Проверьте установку:
   ```powershell
   node -v
   npm -v
   ```
   Должны появиться номера версий. Для сайта нужна версия Node.js 18 или новее.

### 2. Откройте папку проекта
Распакуйте архив, например в `C:\Users\Имя\ala-too-inn`, и перейдите в неё:
```powershell
cd C:\Users\Имя\ala-too-inn
```
(Подставьте свой путь. Быстрый способ: откройте папку в Проводнике, нажмите правой кнопкой на пустом месте при зажатом Shift и выберите «Открыть окно PowerShell здесь».)

### 3. Установите зависимости и запустите
```powershell
npm install
npm start
```
В окне появится строка «Ала-Тоо Inn запущен». Откройте в браузере http://localhost:3000.
Остановить сервер: `Ctrl + C`.

Если PowerShell пишет, что выполнение скриптов отключено, выполните один раз:
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
и подтвердите буквой `Y`. Либо запускайте командами `npm.cmd install` и `npm.cmd start`.

Если порт 3000 занят:
```powershell
$env:PORT=3001; npm start
```

### 4. Проверка с телефона (необязательно)
Телефон и компьютер должны быть в одной Wi‑Fi сети.
1. В PowerShell выполните `ipconfig` и найдите «IPv4-адрес», например `192.168.1.25`.
2. На телефоне откройте `http://192.168.1.25:3000`.
3. Если Windows спросит про брандмауэр, разрешите доступ для частных сетей.

## Часть 2. Публикация на Render Free

### 1. Загрузите проект на GitHub
1. Установите Git: https://git-scm.com/download/win (все настройки по умолчанию).
2. Создайте аккаунт на https://github.com и нажмите **New repository**. Имя, например, `ala-too-inn`. Галочки «Add a README» и «.gitignore» не ставьте. Репозиторий может быть Private.
3. В PowerShell, в папке проекта (после `npm install`, чтобы появился `package-lock.json`):
   ```powershell
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ala-too-inn.git
   git push -u origin main
   ```
   Git попросит войти в GitHub, войдите через браузер.
   Папки `node_modules` и `data` в GitHub не попадут, это настроено в `.gitignore`.

Если Git пишет, что не знает, кто вы, выполните один раз:
```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "ваша_почта@example.com"
```

### 2. Создайте сервис на Render
1. Зарегистрируйтесь на https://render.com (удобно через GitHub).
2. Нажмите **New +** → **Web Service**.
3. Выберите **Build and deploy from a Git repository**, подключите GitHub и выберите репозиторий `ala-too-inn`.
4. Заполните поля:

   | Поле | Значение |
   |---|---|
   | Name | `ala-too-inn` (из имени получится адрес `ala-too-inn.onrender.com`) |
   | Language | `Node` |
   | Branch | `main` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | `Free` |

5. Нажмите **Create Web Service**. Сборка занимает несколько минут. Когда в журнале появится «Ала-Тоо Inn запущен», а статус станет **Live**, откройте адрес вида `https://ala-too-inn.onrender.com`.

Порт задавать не нужно: Render сам передаёт его в `process.env.PORT`.

### 3. Как обновлять сайт
Измените файлы и отправьте изменения. Render пересоберёт сайт сам:
```powershell
git add .
git commit -m "Обновил цены"
git push
```

## Ограничения бесплатного тарифа Render
По документации Render (https://render.com/docs/free):
- Через 15 минут без посетителей сервис «засыпает». Первый заход после этого грузится около минуты. Форма заявки об этом предупреждает и ждёт до 75 секунд.
- Файлы на диске не сохраняются при перезапуске, обновлении и после сна. Поэтому заявки нельзя считать надёжно сохранёнными в файле.
- На месяц даётся 750 бесплатных часов работы.
- Отправка почты по SMTP (порты 25, 465, 587) на Free закрыта. Для уведомлений используйте Telegram (см. ниже).

## Куда приходят заявки
Заявка из формы попадает на сервер. Он проверяет данные, пересчитывает стоимость и:
1. выводит заявку в журнал Render (вкладка **Logs**). Это всегда работает;
2. присылает сообщение в Telegram, если вы настроили переменные ниже (рекомендуется);
3. дописывает заявку в файл `data/bookings.jsonl` (стирается при перезапуске).

### Уведомления в Telegram (необязательно, бесплатно)
1. В Telegram откройте `@BotFather`, отправьте `/newbot`, выберите имя. Получите токен вида `123456:ABC...`.
2. Напишите своему новому боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (подставьте свой токен) и найдите число в `"chat":{"id":...}`. Это ваш chat id.
4. В Render откройте сервис → **Environment** → **Add Environment Variable** и добавьте:
   - `TELEGRAM_BOT_TOKEN` = токен;
   - `TELEGRAM_CHAT_ID` = число из шага 3.
5. Сохраните, сервис перезапустится.

### Страница со списком заявок (необязательно)
Добавьте в Render переменную `ADMIN_PASSWORD` с вашим паролем. Страница `https://ваш-сайт.onrender.com/admin/bookings` попросит пароль (логин любой). Без этой переменной страница отключена. Список виден только до перезапуска сервера.

## Что менять под вашу гостиницу
- **Цены, номера, туры, сезоны, скидки, дату акции:** `public/js/pricing.js` (настройки вверху файла).
- **Телефон и почта:** `public/index.html`, блок `<footer id="contacts">`.
- **Новости и рейтинги:** `public/js/app.js`, массивы `NEWS` и `RATES`. Сейчас там примерные данные, замените их настоящими.
- **Цвета:** `public/css/style.css`, переменные в начале файла.
- **Фотографии номеров:** сейчас это нарисованные иллюстрации. Положите фото в `public/img/` и в `public/js/app.js` в функции, которая выводит номера, замените `roomSVG(i,r.name)` на `<img src="/img/номер.jpg" alt="...">`.

## Если что-то не работает
- `npm` не найден: закройте и заново откройте PowerShell после установки Node.js.
- Сайт на Render долго открывается: сервис спал, подождите минуту.
- Сборка на Render упала: откройте вкладку **Logs**, ошибка указана в последних строках.
- Заявки не приходят в Telegram: проверьте обе переменные и то, что вы написали боту первым сообщением.
